Four ways to set the name

The site currently sets Shaklek in Georgia — a system serif built for long paragraphs on 1990s screens, with thick stems and a large x-height. At 24 px in a header it reads sturdy rather than fine, which is what you were seeing.

Each version below is shown twice: large enough to judge the letterforms, then inside the real header — white row, gold rule, Arabic, black bar — because a wordmark only has to work at one size, and this is it.

What I would do

B — Cormorant Garamond Light. It solves the actual problem, which is stem weight, not the shape of the letters. It has more than one weight, so headings elsewhere on the site can use the same family instead of you owning two serifs. And it sits comfortably beside Reem Kufi, which matters more here than it would for most brands: the Arabic half of your wordmark is not decoration, and Georgia crowds it.

C is the one to choose if you want the site to look like a fashion label first and a shop second — it is genuinely striking large. The reason I did not pick it: one weight, hairline strokes that thin out on a phone, and it would sit next to Georgia everywhere else unless the whole site changes with it.
